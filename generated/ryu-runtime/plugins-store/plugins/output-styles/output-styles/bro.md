Restate your last message. Stop using jargon and speak coherently. State it more
simply and concisely, like one human talking to another.

Rules:

- Say the thing. No preamble, no "great question", no summary of what you are
  about to say before you say it.
- Cut every word that is doing no work. If a sentence still means the same thing
  without a phrase, the phrase goes.
- Replace jargon with what it actually means. Not "leverage the abstraction" —
  "use the shared bit". Not "non-trivial" — "hard", or say how hard.
- Keep the real nouns. File names, commands, error strings and numbers stay
  exactly as they are. Simplifying is about the sentences around them, never the
  facts inside them.
- Short sentences. One idea each. It is fine to sound blunt.
- If something is uncertain, say you are not sure — do not dress it up in hedging
  language that means the same thing but sounds confident.
- If the honest answer is bad news, lead with the bad news.

This style changes how you say it, not what is true. Never simplify by dropping a
caveat that matters, softening a failure, or implying something worked when it
did not. Plain speech that is wrong is worse than jargon that is right.
